# 提示词（按顺序）

这些是视频里真实用过的提示词，一步一步。每一句都在描述想要的**成品**，而不是点哪里。主角是 After Effects，脚本只是被写得更快。

> `code/demo_3d_montage_flythrough.jsx` 里的 demo 是基础版成品。下面这组提示词展示完整的搭建过程 —— 包括摄像机一开始穿不过去的真实失败，以及一行探针怎么找到原因。

**1. 第一步 — 描述成品，不描述操作**

```
干净的浅色背景，把这几段素材导入，排成一墙卡片
```

得到一墙 footage 卡片，铺在柔和的浅灰底上。缺的素材自动用形状图层占位卡顶上。但它是平的 —— 还没有纵深，没有动起来。

**2. 让卡片沿景深涌进来**

```
让卡片从更深的 Z 处往前涌进各自的位置，一张接一张
```

每张卡从更深的 Z 处往前涌进卡位 —— 和待会儿摄像机往前推同一个方向，不是从顶部掉下来。

**3. 错开并给落定加缓动**

```
给落定加缓动，让它们错开几帧
```

一个错开参数控住整组的节奏，卡片稳稳落定，不是硬切到位。

**4. 聚拢卡片、让摄像机穿过去 —— 出问题的一步**

```
把卡片聚拢、在不同深度重叠、各自倾斜，让一台 3D 摄像机直接穿过去；把它们的入场铺满整段推进
```

第一次跑，摄像机在动，画面却是平的。没有视差，没有穿行感。于是加一行探针读卡片层的 `threeDLayer` —— 结果是 `false`。新导入的 footage 默认是 2D 图层，摄像机直接忽略。这就是静默失败：脚本"成功"了，结果却是错的。

**5. 修复 —— 把卡片打开 3D**

```
修复：卡片改 3D，沿 Z 拉开 + 倾斜，入场 = 沿 Z 涌入
```

把每张卡打开 3D 开关、沿 Z 拉开、加倾斜、聚拢重叠 —— 纵深一下炸开。摄像机真的穿过了一叠卡片，边穿边涌现。（在 demo 里，这就是 `layoutCards` 里的 `layer.threeDLayer = true` 那一行 —— 没有它，穿行毫无效果。）

**6. 落定揭题**

```
摄像机减速时，让 hero 标题随着这股推力涌到位，卡片同时溶解交给标题；浅灰背景让卡片投下柔和阴影，摄像机缓停
```

hero 标题随推力涌到位，卡片同时溶解、把画面交给标题。一束平行光把每张卡的柔和阴影投到背景上。干净落定。

**7. 一处控制全部**

```
把卡片数、聚拢/重叠、倾角散布、揭示窗口、摄像机路径和配色全提进一个 CONFIG 块，让我在一处就能重排整套蒙太奇
```

所有值都进到一个 CONFIG 块里。改一处，整套蒙太奇就重排。

**8. 一步重排**

```
5 张卡，换片源，2 列，重新配色成暖琥珀，重新规划摄像机路线
```

九张卡的蓝调版，改几行就成五张卡的暖琥珀版 —— 换片源、换列数、重新规划运镜、一处重配色。同一条命令，完全不同的观感。（在 demo 里，把 `palette` 那个词改成 `"amber"`，再改 `cards` / `grid` / `camera` 的值，就能自己看到。）
