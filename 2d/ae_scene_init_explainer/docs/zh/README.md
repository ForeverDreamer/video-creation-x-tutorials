# 场景初始化起步 — 免费配套包

视频讲的就一件事：**一条命令，把散落各处的资源 —— 你的视频、图片、音效 —— 对账进一个场景，还踩着你解说词的节拍。** 这个包给你自己动手所需的两样东西：**资源目录约定**（见下）和一个**完整可跑的场景** —— 配套演示里的一切（除成品视频外）都随包分发。

## 包里有什么

| 文件 | 是什么 |
|------|--------|
| `code/demo_scene_init_starter.jsx` | 自包含脚本，建出完整品牌标题 sting —— 背景世界、玻璃感圆角边框、六边形 + 头像标记、大标题、青色强调下划线、tagline、三个响应式变体按钮（LIGHT / DARK / MONO）、顺序配音、定时底部字幕。 |
| `code/images/01_logo.png`、`code/audio/01.wav … 04.wav` | 内置素材 —— 频道头像 + 4 段配音（创作者自有）。任意替换成你自己的。 |
| `code/videos/01_bg_loop.mp4` | **不随包** —— 可选自备。放你自己的暗·慢·低对比 loop，或留空走暗底占位。 |
| `code/assets/SOURCES.md` | 各素材来源 + 许可（创作者自有内置；背景 loop 由你自备）。 |

## 资源目录约定（视频的主题）

一个场景从**布局可预期**的目录里读它的素材。把文件按这个方式摆好，工具就能自动找到每一个 —— 不用手接路径：

```text
<project>/
  videos/         <- 录屏、b-roll、背景 loop        （如 01_bg_loop.mp4）
  images/         <- logo、截图、静帧               （如 01_logo.png）
  images/emojis/  <- emoji PNG（语言中立、共享）     （如 emoji_2728.png）
  audio/          <- 配音 / 解说分段                 （如 01.wav … 04.wav）
  sfxs/           <- 音效、whoosh、点击             （如 01_whoosh.wav）
```

两条值得知道的规则：

- **文件按场景 / 分段编号。** `01_` 前缀 = "场景 1"；配音拆成 `01.wav … 04.wav`。保持编号一致，才能让一条命令把一个场景需要的每个素材 —— 以及每句字幕 —— 对齐排好。
- **emoji 语言中立。** 它们放在自己的 `emojis/` 目录（跨语言共享），**不**放在某个语言子目录下 —— 这是场景"丢图标"的高发静默失败陷阱。

起步脚本就演示了这点：它从这些目录读素材。头像与配音随包发；把你自己的暗色 loop 放到 `videos/01_bg_loop.mp4` 作背景世界（否则退回暗底占位）。任意换成你自己的、重跑 —— 删掉一个则那一处优雅降级，所以它永远能跑。

## 跑一下 demo

1. 打开 After Effects。
2. `文件 > 脚本 > 运行脚本文件...`，选 `code/demo_scene_init_starter.jsx`。
3. 出现一个叫 `Scene Init Starter` 的合成，里面是完整 sting —— 背景世界、头像、标题、按钮，以及带定时字幕的配音。按小键盘 `0` 做 RAM 预览即可听到。
4. 把任意内置文件换成你自己的（`images/01_logo.png`、`audio/01.wav` …）再跑一次 —— 场景会拾取改动。

## 调成你自己的

所有可调项都在脚本顶部的 `CONFIG` 块里：

- `brandTitle`、`tagline` —— 你的频道 / 品牌名和标语。
- `captions` —— 底部字幕行，一句对一段配音（按段定时）。
- `variantLabels` —— 三个响应式变体按钮的文字（默认 `LIGHT` / `DARK` / `MONO`）。
- `accent` —— 边框、头像环、下划线的强调色 `[r, g, b]`（0–1）。试试暖橙 `[0.98, 0.55, 0.15]`。
- `bgColor`、`titleColor`、`taglineColor`、`captionColor` —— 背景世界和文字颜色。
- `fontName` —— 字体，用 PostScript 字体名（`ArialMT` = Arial Regular；用无空格名）。
- `bgVideo`、`logoImage`、`voFiles` —— 素材路径，相对脚本所在目录（`bgVideo` 为可选自备）。

改一个值，再跑一次，sting 立刻更新。

## 关于这份免费代码

这是一个起步版，不是整集的完整构建。直接跑可能需要小调整 —— After Effects 版本、字体、操作系统差异都可能不同。如果你只想**看懂一个场景是怎么从它的资源目录脚手架出来的**，看代码跑一下就够了。
