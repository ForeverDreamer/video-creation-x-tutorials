# Asset sources / 素材来源台账

> **Bundled in this pack** = the creator's own material only (redistribution is theirs to grant).
> The background world is an **optional drop-in** you supply yourself (not bundled). Record provenance
> for whatever you swap in — see docs/guides/free-asset-sources.md.
> **随本包分发的** = 只有创作者自有素材（再分发权在创作者）。背景世界是**可选自备**（不随包）。
> 换进任何素材都记来源 —— 见 free-asset-sources.md。
>
> Layout (relative to the script) / 布局（相对脚本）:
> `images/01_logo.png` · `audio/01.wav … 04.wav` (bundled) · `videos/01_bg_loop.mp4` (you supply)

| Asset | Site / Origin | Source URL | License | Attribution? | Bundled? |
|-------|---------------|------------|---------|--------------|----------|
| images/01_logo.png | Channel-owned 频道自有 | — (creator's own avatar, not third-party stock) | Owned 自有 | No | Yes |
| audio/01.wav … 04.wav | Channel-owned 频道自有 | — (creator's own voiceover, EN) | Owned 自有 | No | Yes |
| videos/01_bg_loop.mp4 | Pexels (you supply) | e.g. <https://www.pexels.com/video/a-dark-green-background-with-some-dark-green-lights-19705424/> | Pexels License | No | No — optional drop-in |

> The background loop is NOT shipped (kept small; Pexels loops are a plain swap). Drop any dark / slow /
> low-contrast abstract loop at `videos/01_bg_loop.mp4`, or leave it out for a dark placeholder.
> 背景 loop **不随包**（保持小体积；Pexels loop 可随意替换）。把任意暗·慢·低对比抽象 loop 放到
> `videos/01_bg_loop.mp4`，或留空走暗底占位。
>
> Swapping your own clip / avatar / voice? Record its source (or mark it channel-owned).
> 换成你自己的片 / 头像 / 配音？记来源（或标"自有"）。
